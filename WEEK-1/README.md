# Week 1 - Task Board Application

## Overview

A simple Task Board application built using React and Node.js. The project demonstrates frontend-backend integration by fetching task data from a REST API and displaying it in a user-friendly interface.

## Features

- Display tasks in a Task Board UI
- Fetch task data from backend API
- RESTful API using Express.js
- JSON-based task data
- Clean and responsive interface

## Tech Stack

### Frontend
- React.js
- JavaScript
- CSS

### Backend
- Node.js
- Express.js

## API Endpoint

```http
GET /api/tasks
```

## Project Structure

```
backend/
├── controllers/
│   └── taskController.js
├── data/
│   └── tasks.js
├── routes/
│   └── taskRoutes.js
├── server.js
├── package.json

```

## Installation

```bash
npm install
npm start
```

Server runs at:

```text
http://localhost:5000
```
